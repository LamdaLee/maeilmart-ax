# 원본 사진

여기에 원본을 넣고 `npm run images`를 실행하면 `public/images/*.webp`가 만들어집니다.
이 폴더의 사진은 git에 올라가지 않습니다.

| 파일 이름 | 사진 |
| --- | --- |
| `wallpaper.jpg` | 바탕화면 (하늘·초원). 오른쪽 아래 인장은 변환할 때 아래 6%를 잘라 없앱니다. |
| `mart.jpg` | 흐린 매장 |
| `office.jpg` | 사무실 창가 책상 |
| `desk.jpg` | 노트북과 의자 |

확장자는 jpg, jpeg, png, webp 중 아무거나 괜찮습니다.
